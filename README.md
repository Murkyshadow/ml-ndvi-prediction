Репозиторий содержит полный пайплайн машинного обучения для предсказания вегетационного индекса NDVI с использованием только радарных данных Sentinel-1 (SAR) и метеорологии. Оптические каналы (Sentinel-2) в модели не используются и служат исключительно для вычисления целевой переменной.

Архитектура:
В основе решения лежит каскадный ансамбль градиентного бустинга (LightGBM). Пайплайн включает в себя бинарный классификатор (растительность/почва), класс-специфичных экспертов (с использованием асимметричной квантильной функции потерь для борьбы с переоценкой) и мета-гейт для финальной маршрутизации. Для валидации применена строгая географическая кросс-валидация по тайлам, исключающая утечку данных.

Результаты:
На отложенной тестовой выборке достигнуты показатели MAE 0.0576 (цель < 0.06 выполнена) и R² 79.85%. В репозитории также представлен детальный анализ ограничений метода, доказывающий, что дальнейший рост R² без оптических данных или полной поляриметрии физически невозможен.
